# สคริปต์เดโมโปรโตไทป์ MIND

## เป้าหมาย

พาให้คนดูเห็นเรื่องเดียวให้จบ:

`Room -> แนบไฟล์ -> เห็น evidence -> ได้ summary / next action`

## เตรียมก่อนเริ่ม

- เปิด MIND ที่ `/`
- อยู่ในโหมดปกติของโปรโตไทป์
- เตรียมข้อความงานค้างสั้น ๆ 1 ชุด
- เตรียมไฟล์ตัวอย่าง 1 ไฟล์ ถ้าจะโชว์ evidence
- ถ้าไม่จำเป็น ไม่ต้องเปิด `/business` หรือ `/pmf-guide`

## วิธีเดโม

1. สร้างห้องใหม่ หรือเลือกห้องเดิมที่ใช้ต่อได้
2. วางข้อความงานค้างที่ดูรกพอสมควร
3. แนบไฟล์ 1 ไฟล์ ถ้ามี
4. กด `ไปต่อ`
5. ชี้ให้ดู evidence chip
6. กด evidence chip เพื่อเปิดรายละเอียด
7. ชี้ให้ดู source / เหตุผล / ประวัติ
8. กด `ใช้ก้าวนี้`
9. ถ้าก้าวนี้ยังไม่ใช่ ให้โชว์ทางแก้ 1 ทาง:
   - `ช่วยแก้ก้าวนี้`
   - `ขอก้าวอื่น`
   - `ฉันติดอยู่`
10. ถ้ามีเวลา ให้กลับไปห้องเดิม แล้วชี้ `กลับมาทำต่อ`

## สิ่งที่ต้องสังเกต

- คนดูลังเลตรงไหนก่อน
- คนดูถามว่าต้องกดอะไรต่อไหม
- evidence ทำให้ก้าวถัดไปน่าเชื่อขึ้นไหม
- ทางแก้ดูเป็นทางออกจริง หรือดูเหมือนวนลูป
- reentry อ่านเป็นการทำงานต่อ หรือดูเหมือนเริ่มใหม่

## สิ่งที่ต้องจด

- จุดลังเลแรก
- คลิกแรกที่คนดูเลือก
- งานหลักจบไหม
- อะไรที่ดูดี
- อะไรที่ยังงง
- ต้องอธิบายเยอะไหม

## ถ้าเริ่มติด

- อย่า redesign หน้างาน
- อย่าแตะ prompt, retrieval, OCR, analytics, หรือ smoke harness
- ย่อเดโมให้เหลือ:
  - วางงาน
  - เปิด evidence
  - ไปต่อ
