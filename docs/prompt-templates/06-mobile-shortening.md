# 06 UX Shortening / Mobile Pass Prompt

Use this before implementation handoff and again after screenshots are available.

## Before You Prompt

- Does first viewport show the active room, current action, and evidence context?
- Is any content duplicated between center and right rail?
- Is the primary CTA visible on mobile?
- Which content can be moved into details/accordion?

## Copy-ready Prompt

```text
/structure
รีวิว UX/UI ของ MIND mock-up นี้ให้สั้นและ mobile-friendly:
[ใส่ screenshot หรือ description]

Criteria:
- หนึ่งหน้าจอควรมีหนึ่งงานหลัก
- center = action ที่กำลังทำ
- right = evidence/studio context
- mobile ต้องไม่บัง CTA หลัก
- ลด long-scroll และข้อความซ้ำ

Output:
- 5 จุดที่ควรลด/ย้าย/ซ่อน
- layout ที่ควรเปลี่ยน
- mobile behavior
- acceptance checklist
```

## Expected Output

- Shortening changes
- Mobile behavior
- CTA visibility checks
- Acceptance checklist
