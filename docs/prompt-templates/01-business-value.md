# 01 Business Value / Research Context Prompt

Use this first for every new MIND mock-up idea. Do not start with UI or code.

## Before You Prompt

- Who is the user?
- What task became stale or interrupted?
- Where is the context scattered?
- Which MIND job does this support: re-entry, rescue, scaffold, evidence, state, or local-first trust?

## Copy-ready Prompt

```text
/narrative
ช่วยวิเคราะห์ feature นี้สำหรับ MIND:
[ใส่ feature idea]

Context:
MIND คือ local-first AI task copilot สำหรับ solo client-facing knowledge workers
Painpoint หลักคือผู้ใช้กลับเข้างานเดิมไม่ถูกหลัง interruption/context switch เพราะ context กระจายอยู่ใน email, notes, files, chat

Output:
- painpoint ที่ feature นี้แก้
- business value
- why MIND beats generic AI/chatbot
- risk ถ้า feature นี้ทำให้ MIND drift เป็น note app / planner / generic chatbot
- one-line narrative สำหรับใส่ UI หรือ slide

Format:
- bullet points only
- keep the copy useful for solo client-facing knowledge workers
```

## Expected Output

- Clear feature thesis
- Differentiator vs. generic AI
- Guardrails
- One-line narrative
